# 📊 Análise IBOV vs SELIC vs Bitcoin

Análise comparativa de três indicadores financeiros brasileiros: Índice Bovespa (IBOV), Taxa SELIC e Bitcoin (BTC).

## 📈 Sobre o Projeto

Este projeto explora a **correlação e evolução** desses três ativos ao longo do tempo, identificando padrões, tendências e oportunidades de análise.

**Objetivo:** Entender como esses indicadores se relacionam e qual foi seu desempenho comparativo.

---

## 🛠️ Tecnologias

- **Python 3.x**
- **Pandas** - Manipulação de dados
- **NumPy** - Cálculos numéricos
- **Matplotlib & Seaborn** - Visualizações
- **Jupyter Notebook** - Análise exploratória
